## What's new in v0.9.0

### Netrunner panel
- Netrunner is now a panel under **Installed mods › Overview** (List and Canvas) instead of its own tab. Its tabs are **Summary**, **Files**, **Conflicts**, **Mod interaction**, **Crashes & logs**, **Launch options** and **WolvenKit**.
- The panel follows the mods selected above: a clicked list row, Canvas tile or graph node, or the ticked rows. Each tab says how many findings name them, with **Show all**.
- **Hide** folds the panel into a one-line strip with the counts of the last check; drag the top edge to resize it.
- The graph is renamed **Mod interaction**. **Selection** picks what happens to the rest of the graph when a node is selected: **Fade by distance**, **Hide unrelated** (only nodes within 1–4 links) or **Highlight neighbours**.
- File map: **Link with graph** selects a mod in the graph when it is selected in **By mod**, and the other way round. **Open in file manager** opens a mod's common folder.

### Installed mods
- Game version and profiles: each column shows the game version first, then a **Stock** tag, then the version's profiles in a dropdown that shows the active profile; **+ Profile** is in the dropdown.
- The Nexus Mods logo marks Nexus categories in the list and in Canvas headings.
- **Figure** (Canvas, Characters and Clothing tag columns): mods placed on a drawn body, one slot per body part or clothing slot. The slot comes from the mod's files (TweakXL item types, depot paths in tweaks and ArchiveXL files), then words in its name, then its tag; a badge shows which. **Read archive paths** lists the mods' `.archive` files with the WolvenKit CLI for more slots (cached). **‹ Board** goes back. Canvas tiles show the mod's picture.

### Modpacks
- Installing a collection now uses a profile of its own by default (**Separate profile**, remembered). The mods enabled before are saved as a profile first when no profile holds them; mods not in the collection are disabled, frameworks stay on. Switch back in Installed mods › Game version and profiles.

### Tags
- Tag suggestion rules were tuned on the whole Nexus catalog for Cyberpunk 2077 and now also use the tags on each installed mod's Nexus page (fetched for your installed Nexus mods, at most weekly).

### Downloads
- Separate files of one Nexus page (add-on packs, optional files such as the LUT packs of LUT Switcher 3) are separate items named by their file title. Only files Nexus links as updates of each other are versions of one item; **Switch to this** only replaces versions of the same item.

### Not tested on live hardware or sites
- Figure and **Read archive paths**: checked with sample mods only, not with the WolvenKit CLI or a real mod list.
- Modpack separate profile: checked with sample data only, not with a real collection install.
- Nexus page tags and the Downloads per-file grouping: checked with sample data only.
- Netrunner panel, profiles row and Nexus logo chips: checked headless only, not in a real build.
- The Windows build is still an unsigned preview.
