## What's new in v0.7.0

### First run
- **Introduction tour**: a walkthrough of the main tabs on first start. **Start tour** in Settings reopens it.
- **First setup** checklist on top of Installed mods while a first-run step is open.
- The sidebar is grouped into collapsible sections. Drag the divider to resize it; double-click resets the width.
- Game installs moved to Settings (**Rescan**, **Add path…**).

### Installed mods
- **Game version and profiles**: mod profiles (named lists of enabled mods) under each game version. **Apply**, **+ Profile**, **Update from enabled mods**, **Rename**, **Delete**. The *stock · no mods* chip disables every enabled mod; unsaved enabled mods are first offered as *Before stock*.
- Selection column: select several mods (or downloads) for bulk enable, disable, tag and **Uninstall**. **On** is now a slider.
- **Dependencies** and **Recommendations** checkboxes add rows under each mod; missing dependencies sort on top.
- **Filter by name**.
- **Patch-note check**: compares installed mods with the official patch notes (Hotfix 1.04 onward) and flags frameworks older than a game patch, mods released before 2.0 and features since added to the base game. Hints only; nothing is changed.
- **ReShade**: installs ReShade from reshade.me as a tracked mod, adds its DLL override to the Linux launch options, checks the shader compiler, installs shader packs from GitHub and switches presets.

### Get Mods and installs
- **Missing requirements** dialog before a Nexus download when required mods are not installed.
- Download queue installs requirements first and FOMOD installers last.
- File picker when a mod has several files.
- Modpacks: missing collection mods show their download-queue state.
- Get mods (signed out): API key field first, with **Open Nexus API keys page**.

### Load order
- Netrunner › File map has a **Load order** view and a **Load order** column: each `.archive`'s position, which files it wins or loses, REDmods last. The Compatibility winner now follows the game's case-sensitive file-name order (or `modlist.txt`).
- **Change order** reorders `archive/pc/mod` archives after a warning. It writes a CPMX2077-owned `modlist.txt`; archives are never renamed. **Reset to file-name order** restores any earlier `modlist.txt`. The order is saved with profiles.
- REDmod's own load order is not covered.

### Netrunner, Graph, debug terminal
- File map › By mod opens the selected mod's whole folder tree.
- Netrunner summary no longer crashes on framework warnings and lists Linux setup problems.
- Graph: click a type in the legend to hide or show it. Frameworks are single nodes. Large libraries stay responsive (redraw once per frame).
- Debug terminal is docked in the sidebar by default; **Pop out** moves it to its own window.

### Linux setup
- *HDR* item: checks display EDID, session, desktop HDR state and driver, then **Set HDR launch options**. Shown as fine when the desktop keeps the display in SDR.

### App updates
- Startup notice when a newer CPMX2077 release is on GitHub (**Show release notes**, **Open release page**, **Dismiss**). Settings › CPMX2077 updates: *Check on startup*, **Check now**. Notify only; nothing is downloaded.

### Windows (preview)
- Pop-out debug terminal no longer freezes. Unit tests now run on Windows in CI.
- The installer is still unsigned (SmartScreen: More info, then Run anyway) and the build is still a preview.

### Not tested on live hardware or sites
- ReShade downloads (reshade.me, GitHub shader packs) and the HDR setup are untested against the live sites and real HDR displays.
- Load order reorder, profiles and the new install-queue commands were checked by unit tests and review only, not in a running app.

### Docs
- User guide and getting-started updated for every change above. `docs/architecture/` is a new Obsidian map of the app and its install logic.
