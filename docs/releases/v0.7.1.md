## What's new in v0.7.1

### Launch options
- **Set launch options** now adds `--launcher-skip`: the game starts without CD Projekt's launcher window (REDprelauncher).
- **REDmod switch** next to *REDmod* in the Frameworks list: adds or removes `-modded` in Steam's launch options, replacing the launcher's mod setting. The choice is kept; **Set launch options** does not add `-modded` back while it is off. Steam must be closed. Greyed out (*not Steam*) for GOG, Epic and Heroic.

### HDR
- When the Proton build has Wine's Wayland driver and gamescope is installed, the *HDR* item offers **Set HDR with gamescope** next to **Set HDR launch options**, then **Use gamescope instead** / **Use Wayland instead**. Switching replaces only the HDR settings.
- The gamescope wrapper adds `--force-grab-cursor` so the camera keeps turning at the window edge. An older wrapper without it is flagged and updated.

### ReShade
- A preset-only download (`.ini` with a `Techniques=` line) now installs to `bin/x64`, also from a FOMOD that puts it in the game root. Before, it went to `engine/config/platform/pc`.
- The preset list also reads subfolders of `bin/x64` (e.g. `bin/x64/reshade-presets/`) and an absolute `PresetPath` written by ReShade's overlay.
- **Find shader packs**: lists which GitHub shader pack ships each missing effect file, with **Install** for packs not yet installed.

### Introduction tour
- New step for **Game version and profiles**.
- The outline and card stay on the element while the sidebar or page scrolls.

### Not tested on live hardware or sites
- HDR (both methods), the REDmod switch and ReShade downloads are untested on real HDR displays and against the live sites.
- The Windows build is still an unsigned preview.
