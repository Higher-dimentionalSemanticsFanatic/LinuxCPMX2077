## What's new in v0.8.0

### RadioEXT
- New section **Installed mods › RadioEXT** (shown once a game is selected). Lists every station in radioExt's `radios` folder, whether made here, by another mod or untracked, with the values radioExt reads from its `metadata.json`.
- **New station** / **Edit**: name, FM number, volume, icon (a game UIIcon record or an existing `.inkatlas` path and part), web stream URL, and songs with an optional fixed play order. Song files are checked against their format before they are copied; names can be taken from ID3, FLAC and Ogg tags.
- Each station is a tracked mod, so disable, delete, verify and profiles work. An untracked station folder is taken over when saved; stations owned by another mod are read-only.
- **Install radioExt** queues radioExt's GitHub release when it is missing.
- Station archives that ship only the station folder (no game path) now install to `bin/x64/plugins/cyber_engine_tweaks/mods/radioExt/radios/`.
- Custom PNG station icons are not supported; use a UIIcon record or a ready-made `.inkatlas`.

### OptiScaler and FSR 4
- New section **Installed mods › OptiScaler**: installs OptiScaler from its newest stable GitHub release as a tracked mod, loaded as `wininet.dll` by default (clear of RED4ext, CET and ReShade), optionally with AMD's FSR 4.1.1 upscaler DLL from the FidelityFX SDK repository, checked against its git blob id and version resource.
- Linux: downloads the prebuilt FSR 4.1.1 shader overrides (each `.spv` checked against its git blob id) with **Off** / **Exact** / **Lossy** per game. A new Linux setup item, *FSR 4 shader overrides*, sets `VKD3D_SHADER_OVERRIDE` in Steam's launch options, with **Remove launch option**. OptiScaler's DLL joins the `WINEDLLOVERRIDES` list.

### Downloads
- Filter box, sortable column headers, and **Downloaded** / **Installed** date columns.
- Files still downloading show as rows with their own progress bar.
- A panel at the top of Get mods and Downloads (shared with the download queue) shows one bar per file, side by side, at a fixed height. Finished bars stay until all are done; the panel clears 8 seconds after the last one finishes, or with **Clear**.

### Not tested on live hardware or sites
- RadioEXT: not yet tested in a real build or in the game. The radioExt release zip layout behind **Install radioExt** is not verified against the live release.
- OptiScaler and the FSR 4 shader overrides: not tested in a real build, in the game or on an RDNA GPU.
- Downloads list and progress panel: checked headless only, not in a real build.
- The Windows build is still an unsigned preview.
