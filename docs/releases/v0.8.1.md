## What's new in v0.8.1

### Installed mods
- The menu entry is now **Overview**, with a **List** / **Canvas** switch. Canvas shows mods as tiles in one column per tag, tag group, Nexus category, source or enabled state; disabled mods are faded and can be hidden. Clicking a tile or heading opens it in List.
- Each mod row shows its Nexus picture (fetched from Nexus image hosts only, HTTPS, 2 MB cap, format checked), with a placeholder for mods without one; hidden when the window is narrower than 1400 px.
- The **On** column is now **Enabled**, next to **Uninstall**, with a note on the difference between the two.
- **Update all** is always shown. It checks for updates, lists each one with old and new version, and asks **Proceed** / **Cancel** before queueing.
- Uninstall confirmations say the downloaded archive is kept; Downloads rows show *not installed* next to **Install**.
- New section **Not installed by CPMX2077**: mods already in the game folder (copied in by hand or by another manager), grouped per archive or folder. They count in Compatibility, the Graph and the File map as *(untracked)*. **Adopt** / **Adopt all** record their files and keep a stored copy without changing the game folder, so Enabled, Verify and Uninstall work on them.
- Sortable **Installed** date column. Disabled mods get **Open stored copy**, and a note says what Enabled and Uninstall do and where stored copies are kept.

### Tags
- Predefined tag set: 12 groups of finer tags than the Nexus categories (for example Visuals: Textures, Lighting, Weather & sky). Switch groups on or off in **Modpacks › Your tags**.
- Installed mods suggests tags as dashed chips, matched from the mod name, Nexus category, installed files, TweakXL records and redscript targets. Click to add, × to dismiss.

### Netrunner
- **Launch options explainer**: splits the Steam launch options into variables, wrapper programs, `%command%` and game arguments, with a bracket under each part and what it does, which Game panel item adds it, and placement problems. The line can be edited or pasted to check it; nothing is written to Steam.
- **WolvenKit**: downloads WolvenKit from its GitHub releases (SHA-256 checked) into the app's data folder. Linux gets the CLI (needs the .NET 10 runtime, not installed by the app); Windows also gets the editor. Shows the required and installed .NET runtime and lists an archive's files.
- **Debug terminal** is renamed **Terminal**.

### RadioEXT
- Stations can take a PNG as their icon. CPMX2077 writes the texture, atlas and archive itself and stages them with the station. **Check icon** reads the archive back with the WolvenKit CLI.

### OptiScaler and FSR 4
- The section is renamed **OptiScaler FSR4.1.1 Lite**.
- Installed with AMD's FSR 4.1.1 DLL, OptiScaler now starts on FSR 4 instead of picking XeSS or FSR 3 by itself.
- Answering **No** to *Use the lossy shaders?* now keeps the previous choice selected.

### Patch-note check
- Mods are ranked by their last update (Nexus page date or newest GitHub release) against the game patches released since, longest without an update first. Feature matches and other findings become notes under each mod.

### ReShade
- The missing-effect check follows the search paths in `ReShade.ini`. When a preset mod's own `ReShade.ini` skips the installed shader packs, the skipped folders are listed with **Add to search paths**.
- **Browse preset mods** opens a Nexus search for ReShade presets in Get mods.

### Other
- Ultra+ card: a conflicting mod that is turned off is shown in green.
- The downloads panel sits at the bottom of the page, so opening or closing it no longer moves the page.
- **Update all** no longer counts mods that were uninstalled after the update check.
- The intro tour lists the new sections.

### Not tested on live hardware or sites
- RadioEXT PNG station icons: the archive is verified with WolvenKit 9.1, display in the game is not yet confirmed.
- WolvenKit download and CLI: not tested in a real build.
- OptiScaler FSR 4 default: OptiScaler loads in the game (confirmed on an RX 7900 XTX with v0.8.0); the new default is not yet confirmed in the game.
- ReShade preset mods: no real preset mod install tested in the game.
- Adopting mods not installed by CPMX2077: checked with sample data only, not on a real game folder.
- Installed mods thumbnails, Overview Canvas, tag suggestions, launch options explainer: checked headless only, not in a real build.
- The Windows build is still an unsigned preview.
